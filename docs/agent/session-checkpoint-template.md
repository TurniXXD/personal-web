# Session checkpoint

Copy this template before ending a long chat. Keep it short enough to use as the opening context of a fresh chat.

```markdown
# Objective

<One sentence describing the current outcome.>

## Decisions

- <Decision and the constraint that led to it.>

## Active files

- `<path>`: <current state or responsibility>

## Verification

- Passed: <focused checks already completed>
- Pending: <final gates still required>
- Failed: <unresolved failure and log path, if any>

## Remaining work

1. <Next concrete step>

## Do not repeat

- <Superseded approach, resolved investigation, or unchanged file that does not need rereading.>
```
